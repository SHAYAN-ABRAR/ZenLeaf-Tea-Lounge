# ZenLeaf Tea Lounge — Tea House Landing Page

A clean, responsive landing page for a tea house, built with **Tailwind CSS** and **DaisyUI**.

## Sections

- **Hero:** "It's good tea time at The Tea House", with a rating badge and an *Explore More* button
- **Featured products:** a card grid of signature teas
- **Milk tea spotlight** and **"Great Tea, Freshly Presented"** highlights (unique taste, premium quality)
- **Client testimonials:** "Meet Our Super Clients"
- **Footer** with link groups and a newsletter sign-up form

## Tech Stack

| Layer | Technology |
| --- | --- |
| Markup | HTML5 |
| Styling | Tailwind CSS (Play CDN), DaisyUI 4 |
| Typography and icons | Google Fonts (Manrope), Font Awesome |
| Hosting | GitHub Pages |

## Run Locally

```bash
git clone https://github.com/SHAYAN-ABRAR/ZenLeaf-Tea-Lounge.git
cd ZenLeaf-Tea-Lounge
# Open index.html in a browser
```

## What I Learned

- Translating a design into Tailwind utility classes
- Building responsive card grids and a split-layout hero section
